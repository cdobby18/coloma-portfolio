# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website repository! This project showcases my skills, projects, experience, and journey toward becoming an AI Engineer and Software Developer.

---

## 🚀 About the Project

This portfolio website was built to:

- Showcase my projects and technical skills
- Present my background and learning journey
- Provide a central place for recruiters and developers to view my work
- Practice frontend development and deployment workflows

The website is designed with a modern UI, responsive layout, and clean user experience.

---

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript
- React.js
- Vite
- Tailwind CSS

---

## 📦 Local Development

1. Install dependencies:

```bash
npm install
```

2. Run the dev server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

4. Preview the production build:

```bash
npm run preview
```

---

## 🚀 Deployment

This project is deployable to platforms like Vercel or Netlify. Ensure `package.json` and the lockfile are tracked in git so the remote builder installs dependencies and runs the `build` script.
